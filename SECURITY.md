# Security Policy

## Supported versions

Only the latest released Alpha Jump version receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting form for this repository.
Do not open a public issue for a suspected security vulnerability. Include
reproduction steps, affected version, and any relevant logs with credentials,
tokens, and private server details removed.

We will acknowledge the report privately, investigate it, and coordinate a fix
before public disclosure where practical.
